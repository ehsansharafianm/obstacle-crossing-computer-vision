# 2026-09-02 — Repo reorg, robustness fixes, and the first accuracy validation

A big consolidation + hardening stretch (spanning 08-31 → 09-02), ending with the
first rigid-wand accuracy check. See [[progress-log]] and [[next-steps]].

## Headline
- **Wand validation (test21): precision excellent (~2–6 mm std), but a systematic
  ~6 % SCALE underestimate** — almost certainly the calibration board's true square
  size. This is the single most important finding: it tells us to re-measure the board.
- Repo reorganised into **videos/ (raw) + results/ (generated)**; code untouched otherwise.
- Three real-world "a scene/wardrobe object shares a marker colour" failures found and
  fixed (cone → obstacle, shirt → R_toe, shorts → R_heel).

## Calibration
- **calib16** (gait mat added): floor step failed because the floor board sat far from
  cam2/cam3 (ArUco too small). Fixed with a **multi-scale board detector** in
  `occ.worldframe` (upscales when the board is small/distant). calib16: cam1↔cam2 1.48 px,
  floor 0.67 mm, cam2↔cam3 1.47 px.
- **calib17** (cameras moved): cam1↔cam2 1.66 px (mild), floor **0.47 mm** (best),
  cam2↔cam3 0.76 px. Active calibration for test18–21.

## Pipeline robustness (all driven by real sessions)
- **Obstacle physical-plausibility gate** — reject reds outside the capture volume
  (kills triangulation blow-ups that reproject fine but sit at "infinity"). test17.
- **Obstacle matcher → best camera pair** — test18's cam1 saw a false red (orange
  guidance **cone** + skin); the old matcher anchored on cam1 and rejected 97 % of
  frames. Now it reconstructs from the pair that reprojects best and drops the outlier.
  Obstacle 2 % → 51 %.
- **Teal (R_heel) range tightened** — test20's grey-green **shorts** (hue ~105) read as
  teal (marker hue 96–98); pulled hue cap 106→101, sat floor 140→150. R_heel offset
  329 → 111 mm; R-foot toe-heel std 37 → 10 mm.
- (test19's noisy R_toe was the participant's **patterned shirt** — fixed by neutral
  clothing, not code.)
