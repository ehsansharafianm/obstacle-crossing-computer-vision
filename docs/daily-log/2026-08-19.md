## What we did

**1. Folder reorg (from the confusing `calibration/` vs `calibrations/` twin).**
- `code/sessions/testNN/` = test sessions; `code/calibration/calibNN/` = calib
  sessions (+ shared reference/active files at its root). Commands unchanged.

**2. Camera-sync fixes (`occ/audiosync.py`).**
- The clap detector was rejecting good claps (conf 0) because a global
  cross-correlation locked onto box-drop/footstep sounds. Switched to the
  loudest-isolated-peak method → test05 −5.00 s (conf 12), test06 −5.46 s (conf 55).
- Also explored flash sync (phone light): it registers, but the clap wins for
  this setup (works off-frame, no aiming, already proven). See [[audio-clap-camera-sync]].

**3. Calibration — two sessions.**
- **calib05:** re-recorded extrinsics with a **propped board facing between the
  cameras** (first try failed: only 1 shared pose). Fixed the floor step in code —
  `worldframe.py` now uses the board's **settled (still) period** (a hand-placed
  moving board was smearing corners). Result 0.61 px / 2.46 mm.
- **calib06:** cameras **moved closer** (for bigger markers), big board again,
  added a **board-selection** arg (`run_calib N normal|large`). Result **0.92 px,
  floor 0.65 mm, camera height 986 mm.** See [[calibration-session-recording]].

**4. Markers — found what works.**
- test05 diagnosis: the **red heel competed with the maroon couch + the box's red
  label** → false heels → toe–heel spikes. Purple toe was fine (unique colour).
- Switched to **purple toe + green heel** (both unique, both spherical). Colours
  are now a one-line config (`FOOT_TOE_COLOR`/`FOOT_HEEL_COLOR`). Added a
  **plausibility gate** (drops out-of-bounds 3D points). See [[foot-marker-recording-protocol]].

**5. Results.**
- **test05** (purple toe + red heel, far cameras): std 53.9 mm — red clutter + small markers.
- **test06** (purple toe + **green** heel, **closer** cameras, calib06): std **17.4 mm**,
  clean clearance arcs, gross outliers 2 (was 697). The three changes stacked.

**6. Deck.** Rebuilt the advisor presentation to 6 slides (title/crossing,
markers, calibration, sync, trajectory result, next) with real test06 + calib06 frames.
